ENERGIA PRO+ LOCALE — FILE PWA

Versione senza account e senza servizi di sincronizzazione: i dati delle bollette si conservano nel browser e nel dispositivo correnti.

Per uso locale apri index.html. Per installare la PWA e usare la modalità offline, pubblica tutti i file di questa cartella su un hosting HTTPS, ad esempio GitHub Pages.

Il pulsante ISTRUZIONI nell'app apre una guida con procedure, formule, esempi, backup, installazione e risoluzione dei problemi. Usa Esporta backup per trasferire i dati; Importa backup sostituisce l’archivio presente.
